# Requirements: 端域 DeskRealm

**Defined:** 2026-11-22
**Core Value:** 管理员可在自有环境发布和纳管 Windows 终端，运维可执行可撤销且可审计的授权连接。

## v1 Requirements

保留 [PRD](../docs/DeskRealm-PRD-v0.1.md) 的 FR 和 NFR 编号。BASE 表示 M0 开发产物，QUAL 表示用户指定的最终验收顺序。

### M0 安装与传输基线

- [x] **BASE-01**: 管理员可用固定版本和摘要生成 Linux 中心与单中继的 Compose 配置，配置包含正确发布的原生端口。
- [x] **BASE-02**: 管理员可重复运行安装原型，查看有效中心和公钥指纹，并用持久状态重建服务。
- [x] **BASE-03**: 测试人员可复跑双 Windows 注册、直连、强制中继和服务重建的取证步骤。

### M1 用户、设备与管理面

- [x] **FR-02**: 平台管理员可初始化及管理本地账号，配置 TOTP 和 OIDC，执行受控导入和有审计的恢复。停用后拒绝新登录及续租。
- [x] **FR-03**: 平台管理员可分组并委派按资源、动作、本人或组限制的权限，可签发和撤销限范围、限时 API Token。
- [x] **FR-04**: 获授权用户可查询、审批、分组、轮换、禁用与退役设备。重复登记保留设备 UUID，登记、在线和策略回执分别展示。
- [x] **FR-07**: 用户可创建个人与共享通讯录，配置查看、编辑和管理范围，并在连接时重新判定权限。
- [x] **FR-13**: 授权用户可按范围和会话 ID 查找、保留及导出审计，查询结果区分已确认、缺回执与重复回执。
- [ ] **FR-18**: 各角色可使用中文控制台和适用的客户端入口，以可读状态访问经授权的资源、结果和重试动作。

### M2 受管连接与策略

- [x] **FR-08**: 获授权用户可通过设备 ID 发起远控，使用直连或中继，并查询本次实际路径。
- [x] **FR-09**: 中心按用户、设备、组、状态、版本和 ACL 作准入决策，受控端执行适用的本地确认或已批准的无人值守策略。
- [x] **FR-10**: 受控端分别约束画面、输入、音频、剪贴板和文件传输，按适用授权、角色、策略及确认的交集放行。
- [x] **FR-11**: 管理员可撤销会话。撤销或账号设备禁用时停止续租，控制台区分已请求、已确认和等待到期。
- [x] **FR-12**: 管理员可发布、分配、灰度和回滚版本化策略，比较设备的期望版本和实际应用回执。
- [x] **NFR-01**: 管理 API、中心连接准入与受控会话入口各自鉴权，默认拒绝未获授权的访问。

### M3 部署与自动化交付

- [x] **FR-01**: 管理员可配置镜像、HTTPS、数据与可选中继，在受支持空机上初始化中心。重跑保留公钥、中心身份和数据。
- [ ] **FR-05**: 发布管理员可构建固定版本的品牌安装包，验证签名并查询模板、源码、摘要及公开连接配置。
- [ ] **FR-06**: 获授权用户可获取分组发布的安装包。终端免填中心信息并用单独发放的限时凭据入组或申请审批。
- [x] **FR-14**: 管理员可从任务入口接入区域中继。节点注册、健康、地址及容量达到条件后入池并可重试。
- [x] **FR-15**: 两端向合规候选采样，主控选最小双端 RTT 之和。样本不足时按规则回退，重连时重选，结果可查。
- [ ] **FR-16**: 任务支持记录对象、步骤、日志、结果与失败项，并按授权恢复、重试或取消尚未执行步骤。
- [ ] **FR-17**: 管理员可备份并恢复中心身份与数据，分批发布新版本，失败时暂停并执行已验证的兼容回滚或恢复。
- [ ] **FR-19**: 管理员可从授权导出样本迁移并核对映射、权限与回切，查询时可识别原版试点设备和受管终端。
- [ ] **NFR-02**: 安装包签名可验证，设备入网凭据与签名私钥通过各自受控路径管理，资源操作符合授权范围。
- [ ] **NFR-04**: 安装与任务重试保留身份并去重，恢复保留中心公钥、策略与审计关联，中继可独立更新恢复。
- [ ] **NFR-05**: 管理员可查询连接路径、拒绝、容量、双端 RTT、回退、任务积压、策略回执及撤销耗时。

### 首版目标环境验收

- [ ] **NFR-03**: 在真实直连及中继路径记录在线撤销和失联租约到期，按文档目标核对 5 秒内回执及 35 秒内停止控制。
- [ ] **NFR-06**: 用实际 Linux 与 Windows 矩阵核对部署、升级与回滚并据此发布支持范围。
- [ ] **QUAL-01**: 先验 Linux 中心和一台中继，再用两台 Windows 验证注册、直连、强制中继及原公钥在服务重建后的可用性。
- [ ] **QUAL-02**: 基础拓扑通过后，按 PRD 的 AT-01 至 AT-09 检查受管会话、双区域选点、签名、迁移和任务恢复证据。

## v2 Requirements

M4 包括浏览器主控、原生 LDAP、邮件验证和恢复、更多平台、集中录像及高级会话能力。

## Out of Scope

首版采用单组织、单活中心和备份恢复。多组织共享实例和中心多活超出当前部署模型。
