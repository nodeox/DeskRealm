# 03-02 连接 ACL、设备策略与应用回执

| 工作 | 提交 | 开发证据 |
| --- | --- | --- |
| ACL 草稿、发布、归档、预览和同事务评估 | `c9122ee` | `rules` 两个具名 PostgreSQL 竞态测试，验证默认拒绝、拒绝优先、范围、撤权及并发操作 |
| 不可变设备策略、优先级、灰度、修订回滚和签名回执 | `4ca819a` | `policies` 两个具名 PostgreSQL 竞态测试，Go 与 Rust 回执协议向量，M1 全套回归通过 |

策略按设备、归属用户、主设备组、组织默认选择。灰度分桶由分配 ID 和设备 UUID 固定，回滚产生新修订。期望和已应用版本独立保存。当前设备密钥签署的回执绑定交付 ID、策略版本及载荷摘要。重复回执幂等，乱序或错误设备的回执无法覆盖现状。失败设备可独立重试，已完成设备保留原交付回执。

下一计划 [03-03](03-03-PLAN.md) 在签发、核销及续租时复用 ACL 评估和当前已应用能力，接入状态机、撤销和审计。Windows 端执行与目标环境实机验收留到相应阶段。
