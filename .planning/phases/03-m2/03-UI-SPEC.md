# M2 界面约定

沿用 M1 中文工作台、角色导航、表格、确认对话框和移动宽度布局。采用同一状态词和状态提示，显示加载、空态、权限不足、提交冲突、回执等待及刷新结果。组合页面和直达 URL 使用同一服务端权限。输入从键盘可操作，关闭对话框恢复触发项焦点。

| 入口 | 行为与状态 |
| --- | --- |
| 访问策略 | 筛选规则、预览来源和目标及用途，显示拒绝、可授予操作和匹配策略。发布和回滚前显示受影响范围。用错误与状态提示区分冲突、等待应用和本机应用失败。 |
| 设备详情 | 分列呈现登记、认证心跳在线、期望与已应用版本。显示最近回执时间、失败字段和可执行操作。 |
| 会话与审计 | 会话列表、详情、路径、时间线、租约截止时间和审计筛选通过同一会话 ID 关联合并。具备撤销权限时显示确认按钮。明确区分撤销已请求、等待租约到期、收到端点断开回执和已到期。 |
| Windows 主控 | 显示已认证用户、中心、终端状态和目标。支持设备 ID 和获准的通讯录引用。会话标出实际直连或中继路径、可使用操作和权限收缩或中断结果。 |
| Windows 受控端 | 有人值守请求显示已认证的发起者、用途和操作，提供接受、缩小操作和拒绝。有效的无人值守策略可免弹窗，仍在本机显示当前会话及可操作的断开入口。 |

在 Go/Vue 生产构建与真实 API 的 Chromium 回归核对审批、策略、回执与撤销。受管 Windows 构建和端点测试另行记录，Phase 5 复核实际输入、显示和撤销时间。
