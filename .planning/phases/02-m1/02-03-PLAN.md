| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-02-10 | Elevation of privilege | internal/m1/devices.go, internal/m1/addressbook.go | high | mitigate | 实时双组校验、册与设备权限交集、对象列表同一作用域。 |
| T-02-11 | Tampering | internal/m1/devices.go | high | mitigate | 数据库状态转换锁、原凭据撤销和稳定 ID 历史。 |
| T-02-12 | Repudiation | internal/m1/addressbook.go | medium | mitigate | 审计、授权变更及 outbox 原子提交。 |
| T-02-SC | Tampering | Existing locks and standard library | high | mitigate | 保持已审核锁与标准库签名验证，禁止增设未审核依赖。 |
