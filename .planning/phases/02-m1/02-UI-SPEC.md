# M1 端域控制台界面约定

页面遵循[界面设计](../../../docs/DeskRealm-UI-Design-v0.1.md)和[原型第 1–3、6–8 页](../../../docs/DeskRealm-UI-Prototype-v0.1.pdf)。首登切片贯通一次性初始化、本地登录与已登录工作台，剩余计划填充可操作模块。

## Visual System

- 中文 Web 品牌「端域 / DeskRealm」，遵循文档的 Noto Sans CJK SC、苹方、微软雅黑字体顺序。
- 主色 `#5148DD`，背景 `#F5F7FB`，卡片 `#FFFFFF`，正文 `#192033`，辅助文字 `#617087`，边框 `#E5EAF3`。正文显示文字状态，颜色用于辅助。
- 工作台使用约 208 px 侧栏、64 px 顶栏、28–32 px 内容边距、12 px 卡片圆角和 4 px 间距单位。窄屏可展开导航与查看详情。表单一次聚焦一个流程，主按钮对应当前提交动作。

## Pages and States

| 页面 | 必需状态与操作 |
| --- | --- |
| 首次初始化 | 读取主机发放的一次性票据，设置组织、首个管理员和密码。展示票据已用、过期或入口失效，清理浏览器地址中的票据。初始化成功进入登录。 |
| 登录 | 本地账号、密码及已启用身份方式。提交后从真实 API 恢复会话并加载角色可用页面。失败提示明确聚焦可修正字段。 |
| 概览 | 展示真实可访问指标、待办和近期记录。未接入的指标及模块按交付状态呈现，避免用示例数据模拟实测结果。注销操作显示于身份入口。 |
| 用户与权限 | 查看、创建与委派依作用域展示，表格与详情保持过滤条件。停用、重置和回收 Token 前确认主体、对象和影响。 |
| 设备、通讯录 | 分别展示登记、在线和策略回执。提供适用的审批、分组、分享和管理动作。 |
| 审计、任务 | 支持真实范围过滤、事件关联、失败原因、受影响对象、回执状态及有权重试。 |

## Interaction

表单字段有标签和错误关联，加载与结果可由辅助技术读出，键盘焦点可见。抽屉、弹窗和窄屏模式保留身份、状态与可用动作。跨作用域过滤在 API 执行。界面从服务端权限决定是否展示动作。

## Acceptance

使用真实 API 验证初始化、登录、退出、角色入口、设备审批、通讯录和审计任务。PC 和窄屏验证导航、键盘和错误。源文档颜色和布局用于开发期对照。Linux 与双 Windows 目标验收统一在 Phase 5。
