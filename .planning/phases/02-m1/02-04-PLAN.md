| Boundary | Description |
|---|---|
| Scoped browser → audit/export/task API | 实际主体决定可查询和重试的行、操作与导出结果。 |
| Worker or receipt → database/outbox | 同一对象的领取、回执和业务状态以数据库版本同步。 |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-13 | Information disclosure | internal/m1/audit.go | high | mitigate | 列表、详情、导出使用同一作用域与历史组织组，保密字段排除。 |
| T-02-14 | Repudiation | internal/m1/audit.go, internal/m1/tasks.go | high | mitigate | 同事务追加，保留实际结果、稳定关联及受信重复回执。 |
| T-02-15 | Tampering | internal/m1/tasks.go | high | mitigate | 对象幂等、版本回执、锁定领取、租约、仅允许失败项重试。 |
| T-02-16 | Elevation of privilege | web/src/tasks.ts, internal/m1/tasks.go | high | mitigate | 后端授权每次重试的对象，界面展示当前能力。 |
| T-02-SC | Tampering | Existing lockfiles | high | mitigate | 只沿用已审依赖与固定数据库镜像，门禁检查解析的版本。 |
