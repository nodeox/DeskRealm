# 04-05 签名发布、分组下载与免填登记

| 工作 | 开发验证 |
| --- | --- |
| 构建与开发签名 | x64、ARM64 原生工件和启动程序来自锁定源码。开发 ZIP 校验模板、公开配置、架构、来源和摘要。Authenticode 安装器绑定相同归档、批准证书和独立验签证据。 |
| 分组发布 | 中心在批准发布后持久化已验证的工件。浏览器可发布并下载安装器。组外、换包、伪造证据、撤回和同证据重试均已验证。 |
| 设备登记 | 启动程序读取公开配置，保留本机密钥并用单设备凭据持钥登记。端点在登记回执丢失后可重试原挑战。 |
| 组织部署 | `deskrealm-deploy` 使用单设备组令牌下载签名安装器，并发放、查询和撤销本令牌创建的凭据。PostgreSQL 用例贯通审批和签名策略回执。 |
