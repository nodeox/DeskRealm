# 04-04 双端 RTT 与受管多中继

| 工作 | 开发验证 |
| --- | --- |
| 候选与双端 RTT | 按授权、站点网段和节点状态确定候选。Rust 两端对两个实际 `hbbr` 提交签名样本。 |
| 中心选点与回退 | 双端中位 RTT 之和最小、并列、缺样回退、过期顺序和容量变化均有回归。 |
| 区域配对与转发 | 实际 `hbbs` 会合、双角色票据、节点配对回执、端到端加密、核销及续租通过。首选连接失败后，同轮次切换到下一节点。 |
| 断线与会话详情 | 停止实际转发节点。旧会话上报中断且旧授权不能创建新轮次。再次发起时，取得新授权、连接和轮次并转向健康节点。工作台按现有授权展示实际路径、样本、选点和失败原因。 |

下一计划为 04-05 签名构建、分组下载与免填登记。Linux 和双 Windows 的目标环境验收仍在 Phase 5。[开发验证](04-VALIDATION.md#04-04-断线重选与工作台)
