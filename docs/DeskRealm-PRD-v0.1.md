# 端域 DeskRealm 产品需求文档

**v0.1 评审稿 · 2026-11-22**

项目名为端域 DeskRealm，仓库名建议使用 `deskrealm`。面向运营和运维的 Web 应用称为「端域控制台」，安装在设备上的桌面应用称为「端域远程客户端」。技术实现和需求追踪见 [DeskRealm-System-Design-v0.1.md](DeskRealm-System-Design-v0.1.md)。

## 1. 产品目标

端域是一套自托管远程桌面与终端管理平台。企业或团队在自有服务器上管理账号、设备、访问策略和区域中继。运维人员从已授权的设备列表发起远程连接，管理员可以查看会话、撤销访问并追溯操作。

首版应让管理员从空服务器完成部署，再发起一次客户端发布。终端用户下载安装后自动连接指定中心，并按入网授权加入设备组或进入审批。服务器地址、公钥和中继由部署与发布流程处理。管理员能在控制台看到任务、设备与策略的实际结果。

功能比较以 RustDesk Server Pro 1.8.8 的已公开能力为基准。端域采用自己的名称、界面与交付体系。定制客户端构建以 RDGen 为实施参考。 [官方 Pro 功能][official-pro] · [RDGen][rdgen]

### 首版范围

| 项目 | 首版范围 |
| --- | --- |
| 部署模型 | 每个安装实例服务一个组织。Linux 容器化中心及区域中继，支持独立内网或公网部署。 |
| 客户端 | Windows 主控与受控端。支持范围按通过安装、连接与更新测试的架构发布。 |
| 管理能力 | 本地账号、TOTP、OIDC、用户组、设备组、委派、通讯录、ACL、策略、审计和 API Token。 |
| 连接能力 | 直连、多区域中继自动选点、已授权的有人值守与无人值守访问、会话权限与撤销。需要中继时按两端实测往返时延选择节点。 |
| 部署与交付 | 中心一键安装、中继一键接入、签名客户端构建与免填配置、终端登记和策略同步、任务查询、升级回滚。 |
| 后续阶段 | 浏览器主控、原生 LDAP、邮件验证与恢复、多端扩展、集中录像和按平台开放的高级会话能力。 |

## 2. 使用者与权限

| 使用者 | 主要操作 | 授权范围 |
| --- | --- | --- |
| 平台管理员 | 初始化组织，管理账号、权限、节点、版本和备份。 | 组织全局资源，操作进入审计。 |
| 组管理员 | 管理被委派的用户、设备、登记审批、策略与发布。 | 仅限指定的组与动作。 |
| 运维人员 | 查看有权使用的设备及通讯录，发起会话，查看本人会话。 | 连接资格取决于 ACL。会话操作取决于控制角色、终端策略和适用的确认。 |
| 审计员 | 查询连接、文件、告警和管理事件，按授权导出。 | 只读及明确授予的导出权限，受范围限制。 |
| 终端使用者 | 安装客户端、登录、查看登记进度和接受访问请求。 | 自己的终端及获授权的操作。 |

管理角色用于判定后台页面与资源操作权限。连接 ACL 用于判定谁能连接哪台设备。控制角色用于判定已经建立的会话可使用哪些能力。

## 3. 主要用户流程

1. **初始化中心。** 管理员在目标 Linux 主机运行安装命令，设置域名、证书模式和镜像源。安装完成后通过一次性初始化入口创建首个本地管理员，取得已验证的中心连接配置。
2. **接入区域中继。** 在控制台添加节点并取得部署命令，在目标主机运行。节点登记、上报状态并完成探测后进入中继候选池。
3. **发布客户端。** 管理员选择品牌模板、版本和发布组。平台取用中心配置，构建、签名并验证 Windows 安装包，然后按发起时的发布范围提供下载。
4. **登记设备。** 终端首次启动自动连接中心。受管部署通过组织渠道单独下发限时入网凭据，按批准规则加入目标组或等待审批。策略生效后控制台显示回执。
5. **发起远控。** 运维人员从设备列表或通讯录连接目标。中心判定能否连接与操作范围。受控端执行适用的确认和权限检查。需要中继时，两端测量候选节点，主控客户端自动选出双端往返时延（RTT）之和最小的合规节点。
6. **维护与审计。** 管理员可停用账号、撤销设备、断开会话或发起灰度升级。控制台展示任务结果、历史记录及重试或恢复情况。

## 4. 功能需求与完成条件

### 安装、账号与设备

| 编号 | 功能 | 需求 | 完成条件 |
| --- | --- | --- | --- |
| FR-01 | 中心一键自托管 | 安装、迁移和启动过程可追踪，支持现有运行时或受支持 Linux 空机。按部署选项配置 HTTPS、可选默认中继、镜像源和持久数据。首次通过单次初始化入口创建管理员。 | 空机完成初始化并可登录。安装中断重跑保留中心身份、公钥和数据，界面给出未通过的可达性检查。 |
| FR-02 | 用户与身份 | 创建、邀请、启用、停用、恢复、移交和归档。支持本地密码、TOTP、OIDC、登录会话撤销及账号恢复。支持受控的批量导入。 | 无外部身份源可初始化并登录。停用账号后拒绝新登录与续租。归档保留可追溯的历史身份。 |
| FR-03 | 分组、委派和 API Token | 管理用户组、设备组、后台角色、控制角色。后台角色可按组织、本人或组委派。Token 可指定用途、范围、有效期并可撤销。 | 组管理员可操作授权组。越界读取和写入被拒绝。撤销 Token 后，其操作被拒绝且审计可查。 |
| FR-04 | 设备台账与入网 | 设备登记、审批、归属、分组、改名、标签、身份轮换、禁用、恢复和退役。列表同时显示登记状态、连接状态、版本与策略回执。 | 同一设备重试登记沿用原身份。未知凭据无法通过审批边界。禁用阻止新会话和续租。退役记录仍可追溯。 |
| FR-05 | 定制客户端构建 | 预置名称、图标、中心 ID Server、HTTPS API Server 和服务器公钥。以 RDGen 为参考执行版本化模板、受控构建、签名、验证和产物下载。 | 用同一模板构建签名包。干净 Windows 终端安装后自动向正确中心请求连接。控制台能查到源码版本、模板版本、签名与产物摘要。 |
| FR-06 | 客户端发布与自动登记 | 按组分发版本，支持企业部署工具、权限范围内下载与限时设备登记。允许按组织设定自动批准条件，其他设备进入待审批。 | 同一发布包可分发给多台终端。设备凭据按部署对象发放，成功、待审批或失败结果均可查。终端免填服务器字段。 |

### 远程连接、策略与审计

| 编号 | 功能 | 需求 | 完成条件 |
| --- | --- | --- | --- |
| FR-07 | 通讯录 | 个人及共享通讯录、别名、标签和备注。共享范围支持用户及用户组，角色可查看、编辑或管理。 | 分享与取消分享均可查。点击通讯录条目时重新判断设备连接权限。 |
| FR-08 | 设备连接和数据通道 | 支持按设备 ID 发起远控、通过中心会合、尝试直连及按配置使用中继。连接状态显示当前路径。 | 原版参考客户端跑通注册、直连和强制中继。受管客户端两条路径均执行授权并提供可区分的会话记录。 |
| FR-09 | 连接 ACL 与确认 | 按来源用户或组、主控设备、目标设备或组、账号与设备状态、终端可信版本决定是否允许连接。支持组织要求的本地确认或经设备策略批准的无人值守。 | 未授权跨组、禁用、旧版受管设备以及过期授权均被拒绝。有人值守申请在受控端完成确认后才能开始。 |
| FR-10 | 会话操作权限 | 首版支持只读、键鼠、音频、剪贴板、文件传输等独立能力。生效范围由连接授权、控制角色、终端策略和适用的本地确认共同约束。 | 只读可看画面，输入、剪贴板和文件操作由受控端阻止。各独立能力的允许与拒绝结果均可验证。 |
| FR-11 | 会话撤销 | 管理员可断开会话。停用用户、撤销设备或规则失效后停止续租并通知受控端。控制台显示已请求、已确认或等待租约到期。 | 直连和中继分别通过撤销。在线与失联场景均有停止控制的证据及审计。 |
| FR-12 | 策略下发与回执 | 选择设备、归属用户或设备组策略，支持默认策略、灰度、应用回执和回滚。设备详情展示期望版本与生效版本。 | 指定组升级策略成功，其余设备保持适用版本。错误可定位、回滚可验证。 |
| FR-13 | 审计与导出 | 记录登录、设备、后台操作、授权与撤销、会话路径、文件操作元数据和中继健康。按权限查询、导出并配置保留期。 | 管理员可以用一个会话 ID 关联授权、设备和中继事件。重复回执去重，缺失记录能区分未确认与已完成。 |

### 区域网络与运营

| 编号 | 功能 | 需求 | 完成条件 |
| --- | --- | --- | --- |
| FR-14 | 中继一键部署 | 输入区域、站点、公网或私网端点与容量后生成安装入口。节点执行安装、入网、获取配置、回报版本和验活。 | 两个区域节点从空主机按步骤上线。同一节点重试沿用身份，过期或绑定对象不符的凭据被拒绝。 |
| FR-15 | 多中继自动选点（Multi-relay） | 中心按站点、网段授权、健康和容量下发候选。两端实测，主控客户端自动选择双端 RTT 之和最小且两端测通的节点。没有有效双端样本时按站点或 GeoIP 回退。节点支持排空、停用和调整公布地址。 | 两个不同区域的合规候选均测通时选中双端 RTT 之和最小者。故障节点退出新会话，断线重连时重新测量和选择。选点依据可查。 |
| FR-16 | 部署与交付任务自动化 | 贯穿中心安装、中继接入、构建与发布、设备登记和升级。按任务查看每个对象的步骤、结果、日志和失败原因，可重试失败项或取消尚未执行步骤。 | 构建或部署中断后能恢复查询和执行。批量任务显示逐对象结果，重复提交不产生重复节点、设备或发布。 |
| FR-17 | 升级、备份和恢复 | 支持中心、节点和客户端的版本检查、分批发布、健康验证及兼容回滚。备份覆盖数据库、中心密钥和有效配置，支持恢复演练。 | 升级验证失败时暂停继续发布并记录恢复结果。隔离环境恢复后核对原设备、中心身份、策略与审计。 |
| FR-18 | 中文控制台与终端界面 | 控制台提供概览、用户、设备、通讯录、策略、会话、审计、中继、发布和任务。终端显示所属中心、登记结果和当前会话状态。 | 各角色可从本角色工作入口完成高频流程。错误展示具体步骤和原因。页面与接口权限一致。 |
| FR-19 | 兼容试点与迁移 | M0 用原版客户端验证传输。支持验证已有公开配置导入，以及用授权导出的用户、设备或通讯录清单分批迁移。 | 用试点集合验证字段、ID 映射、权限和回滚。可区分原版试点设备和已纳管终端。 |

## 5. 状态与体验要求

| 对象 | 应显示的状态与信息 |
| --- | --- |
| 用户 | 待激活、已启用、已停用或已归档。身份来源、最近登录、归属组与作用域可查。 |
| 设备 | 登记状态为待审批、已批准、已禁用或已退役。连接状态为在线、离线或未知。另显示策略版本、最后心跳和可执行操作。 |
| 区域中继 | 待安装、安装中、待探测、可用、排空、故障和停用。显示区域、端点、版本与检测结果。 |
| 会话 | 申请、建立、进行中、已请求撤销、等待租约到期和已结束。提供连接路径、中继节点及选点原因、拒绝信息和结束确认。 |
| 任务 | 排队、执行中、等待终端、成功、部分失败、失败和已取消。可查看每个对象与步骤的最新结果。 |

设备台账、会话详情、发布和任务是日常运维的主要入口。会话中的高权限操作要有清楚的请求范围与反馈。终端能够确认当前连接到哪个中心、设备是否已纳管、下一步需要等待什么。

## 6. 非功能要求

| 编号 | 要求 | 验收方式 |
| --- | --- | --- |
| NFR-01 | 端到端权限与身份 | 管理 API 和设备连接分别鉴权。受控端在所有启用会话入口验证授权，并执行操作范围。无人值守纳入明确批准的设备策略。 |
| NFR-02 | 凭据与交付安全 | 终端安装包可验证签名。服务器公钥可以随包分发，入网凭据与签名私钥单独管理。管理员无权跨作用域操作资源。 |
| NFR-03 | 撤销与失联行为 | 正常链路的在线撤销目标为 5 秒内收到终端回执。受控端失联时停止控制的目标为 35 秒内。按真机数据复核目标。 |
| NFR-04 | 恢复与数据一致性 | 部署与任务重试保留身份，重复回执去重。中心恢复保留公钥及审计关联，区域节点可独立更新与恢复。 |
| NFR-05 | 运行可观测 | 可查询注册、授权拒绝、直连比例、中继容量、双端 RTT、选点和回退原因、任务积压、策略应用与撤销耗时。容量按实际会话压测确认。 |
| NFR-06 | 部署可移植 | 适配首发 Linux 和 Windows 测试矩阵，支持适用的公开镜像、组织镜像与离线发布包。真实支持范围以验收清单为准。 |

## 8. 评审与实测前置条件
